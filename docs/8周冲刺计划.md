# 8 周冲刺计划（应届生 · 会 Java/Python · 目标测试岗 · 每天 6h+）

**总投入约 340 小时。** 核心逻辑：**用"测试开发"身份投递，不用"手工测试"身份投递。**

## 每日固定时间分配（6h）

| 时长 | 内容 | 为什么 |
|---|---|---|
| 2.0h | **主线项目**（接口自动化框架） | 决定 offer 档次，必须每天推进 |
| 1.5h | 理论 + 八股（测试理论/网络/数据库/Java+Python） | 决定能否进面 |
| 1.0h | LeetCode 1 题 + 复盘 | 编码面一票否决项 |
| 1.0h | **用例设计实战 3 题**（写完整用例，不看答案） | 面试 100% 考，最高权重 |
| 0.5h | 笔记 + 小结（沉淀到 `tasks/lessons.md`） | 防止学了就忘 |

## 周计划

### 第 1 周：测试内功（决定能否进面）
- 用例设计七法：等价类、边界值、判定表/因果图、正交组合、场景法、状态迁移、错误推测
- 每天 3 题，累计 21 题：登录框、购物车、支付、优惠券、订单状态流转、文件上传、朋友圈点赞
- 缺陷生命周期 + 写 10 份规范缺陷报告（标题/步骤/预期/实际/环境/级别）
- 抓包入门：Charles 或 Fiddler，拆解 3 个真实接口
- **产出**：`用例集.xlsx`（150+ 条）+ `缺陷报告集.md`

### 第 2 周：工程基础
- HTTP：方法、状态码、Header、Cookie/Session/Token/JWT、RESTful
- SQL：牛客 SQL 篇 50 题（join / group by / having / 子查询）
- Linux：`grep tail awk ps netstat top` 查日志与进程
- Git：分支、合并、冲突解决
- **产出**：抓包分析笔记 + SQL 练习记录

### 第 3–5 周：接口自动化框架 ★简历核心项目
- **M1** mock 被测系统（stdlib，离线可跑）
- **M2** common 层 TDD：http_client / token_manager / data_loader / assertions / logger
- **M3** api + testcases 层，≥40 条用例（正例 + 反例）
- **M4** 报告（pytest-html + Allure）+ 并发（-n 4）+ CI（GitHub Actions）
- **产出**：可跑通的框架仓库 + **量化数据**（接口数、用例数、回归耗时、不稳定率）

### 第 6 周：Java 版精简框架 + 刷题强化
- Java 21 + Maven + TestNG/JUnit5 + RestAssured + Allure，做精简版接口测试
- 目的：大厂 Java 栈多，能讲清"两套技术栈的取舍"是硬加分
- LeetCode 热题累计 40 题（字符串/数组/哈希/链表/双指针）
- **产出**：Java 版仓库 + 两套框架对比笔记（面试话术）

### 第 7 周：性能测试 + 自研被测系统
- JMeter：线程组、参数化、断言、聚合报告；对自研系统压测
- 指标口径：TPS / 平均响应时间 / P95 / 错误率；写一份压测报告
- 用 FastAPI 或 Spring Boot 写一个 20 接口的小系统（理解后端，形成差异化）
- **产出**：压测报告 + 自研系统（面试可讲"问题出在哪一层"）

### 第 8 周：面试冲刺
- 简历定稿（1 页，STAR + 量化数据，项目描述可追问到底）
- 八股过 3 遍 + 每天 1 次模拟面试（对着摄像头讲项目 + 讲用例设计）
- 软素质场景题准备：开发说不是 bug 怎么办 / 时间不够怎么测 / 线上事故怎么处理
- 投递：**提前批 > 正式批 > 补录**；大厂 + 独角兽 + 中小 + 测试实习同时投

## 校招时间线（务必盯住）

| 批次 | 时间 | 说明 |
|---|---|---|
| 暑期实习转正 | 3–5 月 | 应届最优解之一，转正率高 |
| 提前批 | 7–8 月 | **竞争最小，必须投** |
| 正式批 | 9–10 月 | 主战场 |
| 补录 | 11–12 月 | 捡漏机会 |

## 里程碑验收（能自证的"完成"）

1. 第 1 周末：能手写 150 条用例，且每条都有明确预期结果
2. 第 3 周末：`pytest` 一条命令跑通 mock 服务全绿
3. 第 5 周末：框架接入 CI，报告可分享，能讲清分层与稳定性治理
4. 第 6 周末：能徒手写 LeetCode 简单题 + Java 版框架跑通
5. 第 7 周末：能独立讲一份压测报告（场景、指标、瓶颈、结论）
6. 第 8 周末：简历定稿，模拟面试 3 次以上不被问倒
